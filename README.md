Original deterministic 4 KB Python 3.13 chess engine for [tiny-chess-01](https://make.fun/bounty/tiny-chess-01).
Uses 10x12 mailbox legal move generation, Zobrist hashing, iterative deepening PVS alpha-beta, quiescence search, null-move pruning, LMR, killer/history move ordering, and tapered PST + king-shield evaluation under a fixed node budget.
